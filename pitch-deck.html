The Pathfinding Engine
How the Engine Scores Paths
Most tools give you a list. WarmPath runs a real graph traversal scoring every path by relationship warmth, then ranking by the weakest link in the chain. Not a recommendation engine. An actual path.
Wpath  =  min(W1, W2 … Wn)  ×  (1 / hops0.5)
each Wi = relationship_type  ×  recency  ×  strength
Wi Recency × Frequency × Relationship type — scored per edge
min() Weakest link wins — one cold handoff kills the entire path
hops0.5 Length penalty — shorter paths rank higher, all else equal
